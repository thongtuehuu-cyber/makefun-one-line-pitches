One sentence, 191 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The same one-sentence pitch, open for a full day instead of an hour, so many more first-time-builder pitches reach the judge. Free to enter, $5 over the top three.

The entry sentence:

> You've been talking about that app idea for years — just describe it in plain words on make.fun and an AI agent will build the first working version for you while you watch, no coding needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the pitch to `out/entry.txt` (UTF-8, 191 characters, within the 1–240 limit).
